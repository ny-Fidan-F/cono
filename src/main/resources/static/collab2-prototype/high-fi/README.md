# Prototypen mit Design

Die gestalteten Prototypen liegen in eigenen Unterordnern. Der erste umgesetzte Entwurf ist **Prototype 1 V2**.

- `prototype-1-v2/index.html` – Links zu den zwei getrennten Widget-Seiten
- `prototype-1-v2/widget1-aktuelles-item.html` – OBS-Widget für das aktuelle Item
- `prototype-1-v2/widget2-item-uebersicht.html` – OBS-Widget für die Item-Übersicht
- `prototype-1-v2/styles.css` – Gestaltung nach dem Figma-Prototyp
- `prototype-1-v2/demo.js` – automatische Testwerte ohne Backend für Widget 1
- `prototype-1-v2/widget2.js` – liest die gespeicherten Testwerte von Widget 1 für Widget 2 aus

Im laufenden Spring-Boot-Projekt sind die Widgets unter `/collab2-prototype/high-fi/prototype-1-v2/widget1-aktuelles-item.html` und `/collab2-prototype/high-fi/prototype-1-v2/widget2-item-uebersicht.html` erreichbar. Die Low-Fi-Ideen bleiben in `../low-fi/`.
